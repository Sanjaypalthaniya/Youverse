# Plus Jakarta Sans

The normal variable font (weights 200–800) is bundled locally and loaded with
Next.js `next/font/local`, `display: swap` and Arial/Helvetica/sans-serif fallbacks.
No Google Fonts request is made at runtime or during production compilation.

Source: [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/plusjakartasans), downloaded 2026-11-03.
License: SIL Open Font License 1.1, reproduced in [OFL.txt](OFL.txt).
The font binary is an intentional application asset, not a browser/tool binary.
